# Roll - Music Discovery & Audio Preview Web App

## 📋 Project Overview
**Roll** is a modern, high-performance web-based music discovery application. It allows users to search millions of tracks, view album artwork, artist details, and listen to 30-second audio previews instantly. The application is built with a minimalist, dark enterprise aesthetic (pure black and deep blue tones) using glassmorphism UI principles.

## 🛠️ Technology Stack
* **Markup & Structure:** HTML5 (Semantic elements)
* **Styling & Design:** Tailwind CSS (via CDN) with custom CSS animations and glassmorphism panels.
* **Scripting & Logic:** Vanilla JavaScript (ES6+, Async/Await, DOM manipulation, event handling).
* **API Integration:** Deezer Public REST API with a robust CORS proxy fallback mechanism and curated offline track library.
* **Deployment Platform:** GitHub Pages

## 🚀 Core Features
* **Global Real-Time Search:** Query tracks, albums, and artists instantly using the Deezer database.
* **Interactive Audio Player:** Custom-built bottom sticky player supporting play, pause, progress bar tracking, and 30-second audio previews.
* **Curated Fallback Library:** Built-in default tracks ensuring the interface remains fully functional and visually rich under any network condition.
* **Responsive Grid Layout:** Fluid design that adapts seamlessly across mobile devices, tablets, and desktop screens.
